# Why Hermes Agent

**Read time: 5 minutes · Task: 5 minutes**

There are many agent frameworks. This course uses **Hermes Agent** because it is open source, runs on common computers and servers, and includes the messaging, scheduling, memory and tool controls needed for this build.

## The open-source landscape

Most agent projects sit at one of two extremes:

- **Developer frameworks** — powerful, but designed for engineers writing code to build agents for others.
- **Chat apps** — easy, but closed, forgetful, and limited to a chat window.

Hermes Agent sits in the middle: **an agent you own and run yourself**, with the convenience of a messaging app and the power of a developer tool — without requiring you to code.

## Why it fits this course

1. **One agent, every face.** Talk to the *same* agent from your terminal, your desktop app, Telegram, WhatsApp, and more. Same memory, same skills.
2. **It self-improves.** A built-in learning loop writes reusable skills from your experience and remembers you across sessions. Every week it gets better at *your* work.
3. **It reaches you.** The messaging gateway connects 20+ platforms, so your agent can message you — and you can message it — from the apps you already use.
4. **Automation built in.** Cron jobs, subagent delegation, batch processing, event hooks, and MCP come out of the box. No glue code required.
5. **Open and inspectable.** It runs on your machine or server and its source can be reviewed. Cloud model and tool providers still receive the data you send to them, so hosting Hermes yourself does not make every workflow private.

## Who maintains it

Hermes Agent comes from **Nous Research**, the lab behind the Hermes open-source models. It is actively maintained — a meaningful difference from a stale experiment someone left on GitHub.
