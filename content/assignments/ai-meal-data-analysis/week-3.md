## Evidence: Clean dataset with reproducible cleaning log

Clean the fictional Rise follow-up dataset by written rules, keep the raw file untouched, and log every change. Download it here: [rise_followup_raw.csv](/pathways/ai-meal-data-analysis/rise_followup_raw.csv).

### What to submit

1. **Your clean dataset.** The clean file, and confirmation of which raw file it came from.
2. **Your cleaning steps.** Your Power Query file or script, so the clean file can be reproduced.
3. **Your cleaning log.** Every rule, the rows affected and the result.
4. **Your data quality note.** Missingness, remaining concerns and possible bias from non-response.

### What the assessor looks for

- Problems found systematically
- Rules applied consistently; nothing guessed
- Steps that reproduce the clean file
- Honest reporting of missing data

## Revision: Act on your feedback

Your mentor will return written feedback on your evidence against the rubric. Revise your work, then explain what you changed. This is where most of the learning happens, so treat it as part of the week, not an extra.

### What to submit

1. **Your revised evidence.** The improved version, or a link to it, with the changed parts marked.
2. **What you changed.** Each feedback point, what you changed in response, and anything you chose not to change and why.
3. **AI-use log.** The rows you added this week: what you asked, what you kept, what you changed and how you checked it.
